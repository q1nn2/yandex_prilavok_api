# БР-21 — PUT /api/v1/orders/{id} возвращает 200 OK при невалидном значении quantity в productsList

- **Приоритет:** Critical
- **Статус:** Open

## Предусловия

Создать набор:

curl --location --request PUT 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/api/v1/orders/66' \
--header 'Content-Type: application/json' \
--data '{
  "productsList": [
    {
      "id": 1,
      "quantity": 0
    }
  ]
}'

## Шаги воспроизведения

1. Отправить PUT-запрос на /api/v1/orders/{id}.
2. В path-параметр id передать id существующей корзины.
3. В body передать productsList с невалидным значением quantity: 
  0, 
  -1, 
   1.5, 
   null, 
   true, 
   false,
   не передать поле quantity.
4. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request с понятным сообщением о невалидном значении quantity.

## ФР

Сервер возвращает 200 OK. Запрос считается успешным при передаче невалидного значения quantity.
