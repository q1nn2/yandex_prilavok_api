# БР-11 — POST /fast-delivery/v3.1.1/calculate-delivery.xml возвращает 200 OK при пустых обязательных XML-элементах

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

создать набор: 

curl --location 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/fast-delivery/v3.1.1/calculate-delivery.xml' \
--header 'Content-Type: application/xml' \
--data '<InputModel>
    <productsCount></productsCount>
    <productsWeight></productsWeight>
    <deliveryTime></deliveryTime>
</InputModel>'

## Шаги воспроизведения

1. Отправить POST-запрос на /fast-delivery/v3.1.1/calculate-delivery.xml.
2. В body передать XML с пустыми обязательными элементами productsCount, productsWeight, deliveryTime.
3. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request с сообщением о том, что обязательные параметры не заполнены.

## ФР

Сервер возвращает 200 OK, хотя обязательные XML-элементы переданы пустыми.

## Комментарий

<response name="Привезём быстро" isItPossibleToDeliver="true" hostDeliveryCost="23" clientDeliveryCost="0">
    <toBeDeliveredTime>
        <min>25</min>
        <max>30</max>
    </toBeDeliveredTime>
</response>
