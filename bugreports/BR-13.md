# БР-13 — POST /fast-delivery/v3.1.1/calculate-delivery.xml возвращает 200 OK при невалидном значении productsCount

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

Создать набор: 

curl --location 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/fast-delivery/v3.1.1/calculate-delivery.xml' \
--header 'Content-Type: application/xml' \
--data '<InputModel>
    <productsCount>-1</productsCount>
    <productsWeight>1.5</productsWeight>
    <deliveryTime>9</deliveryTime>
</InputModel>'

## Шаги воспроизведения

1. Отправить POST-запрос на /fast-delivery/v3.1.1/calculate-delivery.xml.
2. В XML-теле запроса передать невалидное значение productsCount: 
-1, 
1.5, 
null, 
"20", 
"Привет", 
"Hello", 
"%_", 
[1,2,3], 
{}, 
true, 
false,
9999999999.
3. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request с понятным сообщением о некорректном значении productsCount. Значение должно быть числом в допустимом формате.

## ФР

Сервер возвращает 200 OK. Запрос считается успешным при передаче невалидных значений productsCount.

## Комментарий

<response name="Привезём быстро" isItPossibleToDeliver="true" hostDeliveryCost="23" clientDeliveryCost="0">
    <toBeDeliveredTime>
        <min>25</min>
        <max>30</max>
    </toBeDeliveredTime>
</response>
