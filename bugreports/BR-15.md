# БР-15 — PUT /api/v1/orders/{id} возвращает 500 Internal Server Error при невалидном id корзины

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

Создать набор:

curl --location --request PUT 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/api/v1/orders/1.5' \
--header 'Content-Type: application/json' \
--data '{
  "productsList": [
    {
      "id": 1,
      "quantity": 1
    }
  ]
}'

## Шаги воспроизведения

1.Отправить PUT-запрос на /api/v1/orders/{id}.
2. В path-параметр id передать невалидное значение: 1.5, basket, корзина, @3, 9999999999, null, true или false.
3.В body передать валидный список продуктов.
4. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request или 404 Not Found с понятным сообщением о невалидном или несуществующем id корзины.

## ФР

Сервер возвращает 500 Internal Server Error.
