# БР-25 — POST /fast-delivery/v3.1.1/calculate-delivery.xml возвращает 200 OK без сообщения о невозможности доставки вне рабочего времени

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

Создать запрос:

curl --location 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/fast-delivery/v3.1.1/calculate-delivery.xml' \
--header 'Content-Type: application/xml' \
--data '<InputModel>
    <productsCount>2</productsCount>
    <productsWeight>1.5</productsWeight>
    <deliveryTime>6</deliveryTime>
</InputModel>'

## Шаги воспроизведения

1. Отправить POST-запрос на /fast-delivery/v3.1.1/calculate-delivery.xml.
2. В XML-теле запроса передать валидные значения productsCount и productsWeight.
3. В поле deliveryTime передать значение вне рабочего времени службы: 
  6, 
  22, 
  23,
  0 .
4. Нажать Send.
5. Проверить тело ответа.

## Постусловия

Проверить БД

## ОР

Структура ответа соответствует документации:

<response name="Привезём быстро" isItPossibleToDeliver="false" hostDeliveryCost="43" clientDeliveryCost="0">
    <toBeDeliveredTime>
        <min>25</min>
        <max>30</max>
    </toBeDeliveredTime>
</response>
