# БР-12 — POST /fast-delivery/v3.1.1/calculate-delivery.xml возвращает 200 OK при невалидном значении deliveryTime

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

Создать набор:

curl --location 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/fast-delivery/v3.1.1/calculate-delivery.xml' \
--header 'Content-Type: application/xml' \
--data '<InputModel>
    <productsCount>2</productsCount>
    <productsWeight>1.5</productsWeight>
    <deliveryTime>-1</deliveryTime>
</InputModel>'

## Шаги воспроизведения

1. Отправить POST-запрос на /fast-delivery/v3.1.1/calculate-delivery.xml.
2. В XML-теле запроса передать невалидное значение deliveryTime: 
   -1, 
   24, 
   20.5, 
   null, 
   "20", 
   "Привет", 
   "Hello", 
   "%_", [
   1,2,3], 
    {}, 
    true или false.
3. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request с понятным сообщением о некорректном значении deliveryTime. Допустимое значение должно быть числом в формате целого часа от 0 до 23.

## ФР

Сервер возвращает 200 OK. Запрос считается успешным при передаче невалидных значений deliveryTime.
