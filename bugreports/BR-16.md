# БР-16 — PUT /api/v1/orders/{id} возвращает 200 OK при отсутствующем, пустом или неверно названном поле productsList

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

Создать набор:

curl --location --request PUT 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/api/v1/orders/44' \
--header 'Content-Type: application/json' \
--data '{}'

## Шаги воспроизведения

1.Отправить PUT-запрос на /api/v1/orders/{id}.
2. В path-параметр id передать id существующей корзины.
3. В body передать один из вариантов: 
   тело без поля productsList, 
   productsList: [],
   поле productList вместо productsList.
4. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request с понятным сообщением о некорректном теле запроса. Продукты в корзину не добавляются.

## ФР

Сервер возвращает 200 OK. Запрос считается успешным при отсутствующем, пустом или неверно названном поле productsList.
