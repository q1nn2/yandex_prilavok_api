# БР-24 — DELETE /api/v1/orders/{id} возвращает 404 Not Found при удалении существующей корзины

- **Приоритет:** Critical
- **Статус:** Open

## Предусловия

Создать корзину:

curl --location 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/api/v1/orders' \
--header 'Content-Type: application/json' \
--data '{
  "productsList": [
    {
      "id": 1,
      "quantity": 1
    }
  ],
  "deliveryTime": 9
}'

## Шаги воспроизведения

1. Отправить запрос DELETE /api/v1/orders/92

## ОР

На DELETE-запрос сервер возвращает 200 OK.
Корзина удаляется.
После удаления GET /api/v1/orders/92 возвращает 404 Not Found.

## ФР

На DELETE-запрос сервер возвращает 404 Not Found:

## Комментарий

{
    "code": 404,
    "message": "Корзина с id=92 не найдена"
}

## Окружение

Windows 11 Pro 21H2; 
Тестовый стенд API; 
Яндекс.Прилавок 3.1.1.
