# БР-20 — PUT /api/v1/orders/{id} возвращает 500 Internal Server Error при невалидном типе или формате id продукта в productsList

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

Создать набор:

curl --location --request PUT 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/api/v1/orders/58' \
--header 'Content-Type: application/json' \
--data '{
  "productsList": [
    {
      "quantity": 1,
      "id": 1.5
    }
  ]
}'

## Шаги воспроизведения

1. Отправить PUT-запрос на /api/v1/orders/{id}.
2. В path-параметр id передать id существующей корзины.
3. В body передать productsList с невалидным значением id продукта: 
  1.5, 
  "apple", 
   "яблоко", 
   "%_", 
    [1,2,3], {}, 
    true, 
    false,
    9999999999.
4. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request с понятным сообщением о невалидном id продукта.

## ФР

Сервер возвращает 500 Internal Server Error.

## Комментарий

{
    "code": 500,
    "message": "invalid input syntax for integer: \"1.5\""
}

## Окружение

Windows 11 Pro 21H2; 
Тестовый стенд API; 
Яндекс.Прилавок 3.1.1.
