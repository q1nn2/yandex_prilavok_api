# БР-17 — PUT /api/v1/orders/{id} возвращает 500 Internal Server Error при невалидном типе поля productsList

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

Создать набор:

curl --location --request PUT 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/api/v1/orders/44' \
--header 'Content-Type: application/json' \
--data '{
  "productsList": "123"
}'

## Шаги воспроизведения

1.Отправить PUT-запрос на /api/v1/orders/{id}.
2. В path-параметр id передать id существующей корзины.
3. В body передать productsList в невалидном типе: 
  строка "123", 
   число 13,
   объект {"id":1,"quantity":1}.
4. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request с понятным сообщением о некорректном типе поля productsList.

## ФР

Сервер возвращает 500 Internal Server Error.

## Комментарий

{
    "code": 500,
    "message": "productsList.find is not a function"
}

## Окружение

Windows 11 Pro 21H2; 
Тестовый стенд API; 
Яндекс.Прилавок 3.1.1.
