# БР-18 — PUT /api/v1/orders/{id} возвращает 200 OK при Content-Type: text/plain

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

Создать набор:

curl --location --request PUT 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/api/v1/orders/44' \
--header 'Content-Type: text/plain' \
--data '{
  "productsList": [
    {
      "id": 1,
      "quantity": 1
    }
  ]
}'

## Шаги воспроизведения

1. Отправить PUT-запрос на /api/v1/orders/{id}.
2. В path-параметр id передать id существующей корзины.
3. В body передать валидный JSON с productsList.
4. В Headers указать Content-Type: text/plain.
5. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request или 415 Unsupported Media Type, так как endpoint должен принимать JSON с Content-Type: application/json.

## ФР

Сервер возвращает 200 OK и обрабатывает запрос как успешный, несмотря на Content-Type: text/plain.
