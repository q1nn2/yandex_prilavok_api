# БР-14 — POST /fast-delivery/v3.1.1/calculate-delivery.xml возвращает 200 OK при невалидном значении productsWeight

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

Создать набор:

curl --location 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/fast-delivery/v3.1.1/calculate-delivery.xml' \
--header 'Content-Type: application/xml' \
--data '<InputModel>
    <productsCount>2</productsCount>
    <productsWeight>-0.1</productsWeight>
    <deliveryTime>9</deliveryTime>
</InputModel>'

## Шаги воспроизведения

1. Отправить POST-запрос на /fast-delivery/v3.1.1/calculate-delivery.xml.
2. В XML-теле запроса передать невалидное значение productsWeight: 
  -0.1, 
   null, 
   "2.5", 
   "Привет", 
   "Hello", 
   "%_", 
   [1,2,3], {}, 
   true, 
   false,
   999999999.
3. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request с понятным сообщением о некорректном значении productsWeight. Значение веса должно быть числом в допустимом формате и не должно быть отрицательным.

## ФР

Сервер возвращает 200 OK. Запрос считается успешным при передаче невалидных значений productsWeight.

## Комментарий

<response name="Привезём быстро" isItPossibleToDeliver="true" hostDeliveryCost="23" clientDeliveryCost="0">
    <toBeDeliveredTime>
        <min>25</min>
        <max>30</max>
    </toBeDeliveredTime>
</response>
