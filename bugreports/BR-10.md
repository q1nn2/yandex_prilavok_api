# БР-10 — POST /fast-delivery/v3.1.1/calculate-delivery.xml возвращает 500 Internal Server Error при невалидном XML-запросе или отсутствии обязательных XML-элементов

- **Приоритет:** Major
- **Статус:** Open

## Предусловия

создать набор:

curl --location 'https://b9c52f5b-aed7-4de2-a78b-69c29b57eb0d.serverhub.praktikum-services.ru/fast-delivery/v3.1.1/calculate-delivery.xml' \
--header 'Content-Type: application/xml' \
--data '<InputModel>
    <productsWeight>1.5</productsWeight>
    <deliveryTime>9</deliveryTime>
</InputModel>'

## Шаги воспроизведения

1.Отправить POST-запрос на /fast-delivery/v3.1.1/calculate-delivery.xml.
2. Передать один из невалидных вариантов тела запроса:
    XML без элемента productsCount;
    XML без элемента productsWeight;
    XML без элемента deliveryTime;
    пустое тело запроса;
    XML с незакрытым тегом;
    XML с неправильным корневым элементом;
    JSON вместо XML;
    валидный XML с заголовком Content-Type: application/json.
3. Нажать Send.

## Постусловия

Проверить БД

## ОР

Сервер возвращает 400 Bad Request с понятным сообщением о некорректном XML-запросе или отсутствии обязательных параметров.

## ФР

Сервер возвращает 500 Internal Server Error.
